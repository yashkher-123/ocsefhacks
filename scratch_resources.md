# intro to coding in scratch

### for competitors who are completely new to coding, you can still make an awesome project using scratch!!

## below are some resources for learning how to use scratch:

- https://scratch.mit.edu/projects/editor/ - quickstart
- https://scratch.mit.edu/ideas -- homepage for official scratch tutorials and project ideas, has lots of starter code
- https://projects.raspberrypi.org/en/projects?software%5B%5D=scratch -- STEP BY STEP TUTORIALS for 50+ scratch projects; add your own spin!
- https://en.scratch-wiki.info/wiki/Scratch_Wiki:Table_of_Contents/Program -- scratch wiki, info on block types and project creation
- https://www.youtube.com/@griffpatch -- griffpatch, youtube creator with many project tutorials
